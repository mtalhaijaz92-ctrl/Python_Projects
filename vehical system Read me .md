# Vehicle Rental System

## Project Overview

A Vehicle Rental System developed using Python and Object-Oriented Programming (OOP).

The project manages different types of vehicles and calculates rental costs according to the vehicle type and rental duration.

## OOP Concepts Used

- Classes and Objects
- Constructors
- Inheritance
- Method Overriding
- Polymorphism
- `super()`
- Code Reusability

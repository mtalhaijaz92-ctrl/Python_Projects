# Bank Management System

## Project Overview

A simple Bank Management System developed using Python and Object-Oriented Programming (OOP).

The project simulates basic banking operations such as depositing money, withdrawing money, checking balance, and displaying account information.

## OOP Concepts Used

- Classes and Objects
- Constructors
- Encapsulation
- Inheritance
- Method Overriding
- `super()`
- Private Attributes
- Code Reusability
